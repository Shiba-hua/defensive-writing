# 防御性写作

IRON LAW: 之后输出的每一句话，都必须至少命中下方词表（图中原词）中的 1 个词/短语。不含词表词汇的句子不允许出现。不得自造句式、不得增删词条。

## 词表（图中原词，仅此）

**中心**：不是……而是（句中需同时出现「不是」与「而是」）

**外围六大区块**：

| 区块 | 词条 |
|---|---|
| 不能证明（顶） | 不完全、不足以证明、不能仅凭、只能证明 |
| 并非（右上） | 不足以说明、不必然、不能只看、不能只凭、不能仅看、不能做、并不是、不是说 |
| 不等于（右下） | 不能据此、不意味着、不能确认、不能简单、不构成 |
| 不能（底） | 不能把、不保证、不一定、不能承诺、无法证明、更准确地说 |
| 不代表（左下） | 不能确定、不能当作、无法说明、不能断定、不能仅靠 |
| 不能（左上） | 不能推出、不能断言、不能视为、只能说明、不能认定 |

**中间过渡区域**：并不、不等同于、不证明、并不能、不能说明、尚不能、不能

配图见 [assets/hedge-map.webp](assets/hedge-map.webp)，完整排版结构见 [references/hedge-patterns.md](references/hedge-patterns.md)。

## 执行规则

- 只使用上表词条，不新增、不改写、不扩展。
- 输出前把内容拆成独立句子；每一句（含标题、列表项、表格单元中的独立表述）都必须含至少 1 个词条原文。
- 词条嵌入句中时保持字面不变。
- 交付前用脚本逐句自检：

```bash
python3 scripts/check_hedges.py "要检查的文本"
```

退出码 0 表示每句均命中；非 0 会打印未命中的句子。
